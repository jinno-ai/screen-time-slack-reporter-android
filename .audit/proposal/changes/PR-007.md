# PR-007: Runtime Notification Permission Request (API 33+)

**Priority**: Medium  
**Risk**: Low  
**Estimated Effort**: 2 hours  
**Addresses**: ISS-NEW-002

## Problem

Android 13 (API 33+) requires runtime permission for posting notifications. The app declares `POST_NOTIFICATIONS` in the manifest but doesn't request it at runtime. Users on API 33+ won't see error notifications when Slack sending fails.

## Proposed Solution

Add runtime permission request flow in the Settings screen, where notification configuration is most relevant.

## Changes

### 1. Add Permission Request to SettingsViewModel

```kotlin
// In SettingsViewModel.kt
fun requestNotificationPermission() {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
        _uiState.update { it.copy(showNotificationPermissionDialog = true) }
    }
}

fun onNotificationPermissionResult(granted: Boolean) {
    _uiState.update { 
        it.copy(
            showNotificationPermissionDialog = false,
            notificationPermissionGranted = granted
        )
    }
}
```

### 2. Update SettingsUiState

```kotlin
data class SettingsUiState(
    // ... existing fields ...
    val showNotificationPermissionDialog: Boolean = false,
    val notificationPermissionGranted: Boolean? = null,
)
```

### 3. Add Permission Check in SettingsScreen

```kotlin
// In SettingsScreen.kt
val notificationPermissionLauncher = rememberLauncherForActivityResult(
    contract = ActivityResultContracts.RequestPermission()
) { granted ->
    viewModel.onNotificationPermissionResult(granted)
}

// Add info card about notifications
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
    Card(modifier = Modifier.fillMaxWidth()) {
        Column(modifier = Modifier.padding(16.dp)) {
            Text("通知権限", style = MaterialTheme.typography.titleMedium)
            Text("エラー通知を受け取るには通知権限が必要です")
            Button(onClick = {
                notificationPermissionLauncher.launch(Manifest.permission.POST_NOTIFICATIONS)
            }) {
                Text("権限をリクエスト")
            }
        }
    }
}
```

## Expected Impact

- Users on API 33+ can grant notification permission
- Error notifications will be visible after permission is granted
- Better UX for notification configuration
