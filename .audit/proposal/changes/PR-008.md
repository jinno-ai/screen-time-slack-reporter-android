# PR-008: Add Screenshots to README

**Priority**: Low  
**Risk**: None  
**Estimated Effort**: 1 hour  
**Addresses**: ISS-002

## Problem

The README lacks visual documentation. Users cannot preview the app's UI before installation, reducing discoverability and trust.

## Proposed Solution

Add screenshots of key screens to the README with proper formatting and descriptions.

## Changes

### 1. Create Screenshots Directory

```bash
mkdir -p docs/screenshots
```

### 2. Capture Screenshots

Required screenshots:
- Home screen (with usage data)
- Settings screen (webhook configuration)
- Exclusions screen (app filtering)
- Notification example (error notification)

### 3. Update README.md

Add a "Screenshots" section:

```markdown
## Screenshots

<div align="center">
  <img src="docs/screenshots/home.png" width="200" alt="Home Screen" />
  <img src="docs/screenshots/settings.png" width="200" alt="Settings Screen" />
  <img src="docs/screenshots/exclusions.png" width="200" alt="Exclusions Screen" />
</div>

### Home Screen
- Displays today's total screen time
- Shows top 5 apps by usage
- Manual send button for immediate reports

### Settings Screen
- Configure Slack Webhook URL (encrypted storage)
- Set automatic daily send time
- Test webhook connection

### Exclusions Screen
- Filter apps from reports
- View today's app usage
- Toggle exclusions easily
```

## Expected Impact

- Improved README documentation quality
- Better user onboarding experience
- Increased project discoverability

## Verification

1. Verify screenshots are properly sized and clear
2. Check README renders correctly on GitHub
3. Ensure images are optimized for web (<100KB each)
